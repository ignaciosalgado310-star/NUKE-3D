# IRA-DE-SEUS-3D V2

Overhaul completo para Minecraft Forge 1.20.1 / Mohist.

## Comando
`/iradeseus <jugador> <totems>`

Aliases: `/iraseus` y `/zeusira`.

## V2
- Sin BlockDisplay ni modelos construidos con bloques vanilla.
- Avatares 3D propios y animados: Zeus, Thor, Poseidon, Ra y Hades.
- Armas 3D propias por dios.
- Portales, sigilos, vórtices, jaulas, orbes y ondas como mallas renderizadas.
- Partículas PNG propias.
- Proyectiles divinos animados.
- Daño/tótems repartidos durante el ritual.
- Cráter final procesado por presupuesto de bloques para cuidar el servidor.
